# Project-I---Data-Analytics-BikeSalesDashboard
Analyze the company's bike sales data to improve sales performance, understand customer behavior, identify high-performing products and stores, and monitor returns and service revenue. create an appropriate star-schema data model, develop DAX measures, and build an interactive Power BI dashboard.

#### Project Objectives
1.	Clean and transform the raw CSV data using Power Query.
2.	Identify and resolve data-quality issues.
3.	Build a suitable star-schema data model.
4.	Create relationships between dimension and fact tables.
5.	Create calculated measures using DAX.
6.	Develop an interactive and management-friendly Power BI dashboard.
7.	Analyze sales, products, customers, stores, salespersons, returns, and service revenue.
8.	Present meaningful business insights based on the data.

## Dashboard – Executive Sales Dashboard
•	Create KPI cards for Total Sales, Bikes Sold, Customers, Average Order Value, Return Amount, and Service Revenue.
•	Create a monthly sales trend line chart.
•	Create sales by brand.
•	Create sales by region.
•	Create Top 10 Products.
•	Create sales by category.
•	Add slicers for Financial Year, Year, Month, Region, State, Store, Brand, Category, Payment Method, and Order Status.
